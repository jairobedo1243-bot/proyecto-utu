INDICE DE PRIMERA ENTREGA - SGRSI
=================================

Proyecto: Sistema de Gestion de Recursos y Soporte de Informatica
Sigla: SGRSI

Este proyecto queda organizado para la primera entrega solicitada.

IMPORTANTE:
Para la primera entrega se deben usar los archivos listados en este indice.
Otros archivos antiguos de resumen o pruebas no forman parte de la entrega final.


1. HTML + CSS + JAVASCRIPT
==========================

Archivos principales:

- index.html
- css/styles.css
- app.js
- css/bootstrap.min.css
- js/bootstrap.bundle.min.js

Cumple con:

- Maquetacion HTML5 con etiquetas semanticas.
- Estilos CSS3 enfocados en usabilidad.
- Diseno responsive mobile first.
- Uso de Bootstrap como framework CSS.
- Formularios principales del sistema.
- Navegabilidad entre modulos.
- Validaciones del lado del cliente.
- Manipulacion del DOM.
- Manejo de eventos.
- Validaciones personalizadas.
- Control de errores mediante mensajes al usuario.
