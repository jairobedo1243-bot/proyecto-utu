2. DIAGRAMA DEL CODIGO
======================

PROYECTO UTU
|
+-- index.html
|   +-- Estructura semantica del sitio.
|   +-- Contiene login, modulos y formularios.
|
+-- css/
|   |
|   +-- bootstrap.min.css
|   |   +-- Framework CSS usado para grilla responsive y componentes.
|   |
|   +-- styles.css
|       +-- Estilos propios del sistema.
|       +-- Colores, tarjetas, formularios y media queries.
|
+-- js/
|   |
|   +-- bootstrap.bundle.min.js
|       +-- Comportamiento de componentes Bootstrap.
|
+-- app.js
|   +-- Manipulacion del DOM.
|   +-- Manejo de eventos.
|   +-- Validaciones personalizadas.
|   +-- Control de errores.
|   +-- Simulacion de login por roles.
|
+-- database_sgrsi.sql
|   +-- Modelo de base de datos.
|   +-- Tablas y relaciones.
|
+-- documentos .txt
    +-- Relevamiento, planificacion, Git, SO y diagramas.

Explicacion:
El usuario primero debe iniciar sesion.
Si los datos son incorrectos, vuelve al login.
Si los datos son correctos, accede al panel y navega por los modulos.
Cada formulario valida datos y muestra mensajes de resultado.
